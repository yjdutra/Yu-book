## Decisões em vigor

- **Skill registra o que o código faz, nunca o que a fase pretende.** Do PRD só se aproveita
  argumento pronto, por ponteiro.
- Cruza arquivo → catálogo; sítio único com o comentário ao lado → fica na linha. **Alvo de
  auditoria em outro arquivo cruza.**
- **Prescrição e invariante que se tocam separam-se por natureza**: o "como se faz" à skill; o
  estado auditável ao catálogo.
- **Espelhamento frágil vai para `contrato-compartilhado` §4 mesmo sem passar por `shared`**; a
  dívida se declara ali (§4.5).
- **Ponteiro de rota entre skills não é duplicação; cópia do argumento é.**
- **Número medido é memória de agente, não skill.** Envelhece calado.
- **Skill estourando 300: procure a cópia antes de extrair.** Argumento que subiu ao catálogo vira
  ponteiro. Só depois extraia o que se lê *depois* de escrever — nunca a doutrina.
- **Não renumere seção de skill: o número é referência cruzada.** Doutrina nova entra como §0; os
  §N citados fora da skill continuam de pé.
- Não vira registro: fato sem `arquivo:linha` que o audite, e fato com prazo.
- Fato já escrito em `docs/historico.md` ou no `CLAUDE.md` não se copia: vai ao operador.
